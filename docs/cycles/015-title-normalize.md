# 015 title-normalize (C-001)

## Goal
Implement the title rules that every later data tool and the Java backend share: `normalize`, `strip_qualifier`, `has_hangul` and `head`. Pin them with a hand-written vector file (design 014 decisions 3-4; D-015, D-038).

## Interface: `data/songrush_data/titles.py`
- **`normalize(s: str) -> str`** (D-015: spaces, punctuation, case and width ignored; spelling must match). The steps run in this order:
  1. NFKC. This folds width, so `ＡＢＣ` becomes `ABC` and `ｶﾞ` becomes `ガ`.
  2. Lowercase so that Java can match it exactly: Python `str.lower()` (Java `toLowerCase(Locale.ROOT)`), then map `ß` to `ss` and `ς` to `σ`. (`ẞ` lowercases to `ß`.) Full `casefold()` is not used, because Java has no equivalent; the differences left are scripts that never appear in anime titles.
  3. NFD, then remove the combining marks **U+0300-U+036F** (Latin diacritics, so `Ō` becomes `o`), then NFC. Japanese voicing marks (U+3099, U+309A) are not in that range, so `が` stays `が`.
  4. Map the multiplication sign `×` (U+00D7) to `x`, so that `Hunter × Hunter` equals `Hunter x Hunter`; keyboards have no `×`.
  5. Remove every character whose Unicode general category is `P*`, `S*`, `Z*`, `Cc` or `Cf`. Also remove the Hangul fillers U+115F, U+1160, U+3164 and U+FFA0, the variation selectors U+FE00-U+FE0F and U+180B-U+180F, and the ideographic variation selectors U+E0100-U+E01EF.
  6. NFC once more, because removing characters can leave decomposed sequences (`か` + U+3099 becomes `が`).
  - Iterate by code point; Java must use `codePoints()` and `Character.getType(int)`, not `char`. The Unicode version follows the runtime: 15.0 for Python 3.12, 13.0 for JDK 17 (D-030 accepts this rare drift).
  - Nothing else is changed. Digits are kept, and so are letters in any script.
- **`strip_qualifier(s: str) -> str`** removes **one** trailing qualifier, matched case-insensitively on the raw title after trimming.
  - **Boundary:** a qualifier must be preceded by a space, `:` or `,` and must not start the string. When several qualifiers match, the longest wins (`The Final Season` before `Final Season`). Separator characters left at the end are trimmed.
  - **Minimum remainder:** if the remainder contains Hangul, kana or a CJK ideograph, `normalize(remainder)` must have at least **2** characters; otherwise at least **4**. If not, `s` comes back unchanged. The rule is applied after trimming and is otherwise the same everywhere.
  - **Ordinals:** `Nth Season` means a digit ordinal (`2nd Season`, `3rd Season`); English word ordinals such as `Second Season` are not stripped.
  - Nothing matching also returns `s` unchanged.
  - The qualifiers:
  - `Season N`, `, season N`, `N(st|nd|rd|th) Season`, `Part N`, `Final Season`, `The Final Season`;
  - `第N期`, `N기`, `시즌 N`, `N화`;
  - `(YYYY)`, `(TV)`, and a parenthetical that ends in `애니메이션`.
  - N is one or more digits.
- **`has_hangul(s: str) -> bool`** is true when `s` has a code point in U+AC00-U+D7A3.
- **`head(s: str) -> str | None`** returns `normalize` of the text before the first `/` or `:`, or `None` if `s` has neither, or if that normalized text has fewer than 4 characters.

## Acceptance criteria (each is a test)
1. **`contracts/normalize-vectors.json`.**
   - It is a JSON object `{"version": 1, "vectors": [{"input": ..., "expected": ...}, ...]}` with at least 40 pairs.
   - It is **hand-written from D-015 and this spec**, never generated by running code.
   - Invisible and combining characters are written as JSON escapes: one backslash, `u` and four hex digits inside the JSON string. After `json.loads`, no input contains a literal backslash followed by `u`; the test asserts it. Java reads the file as UTF-8 (`Files.readString`).
   - It covers:
     - full width;
     - case, including `ß`, `ẞ`, `ς` and `ΣΟΦΟΣ`;
     - `Hunter × Hunter` and `Hunter x Hunter` (both `hunterxhunter`);
     - punctuation and spaces;
     - symbols such as `☆`, `×` and `♪`;
     - Hangul, kana and kanji;
     - Latin diacritics, and dakuten that is kept;
     - NBSP, ideographic space, zero-width space, soft hyphen, BOM and the Hangul fillers;
     - digits;
     - a title that normalizes to the empty string.
   - pytest runs every vector through `normalize`.
2. **`strip_qualifier` table tests:**
   - `Shingeki no Kyojin Season 3` gives `Shingeki no Kyojin`.
   - `Attack on Titan Final Season` gives `Attack on Titan`.
   - `Hunter x Hunter (2011)` gives `Hunter x Hunter`.
   - `나루토 (애니메이션)` gives `나루토`.
   - `귀멸의 칼날 2기` gives `귀멸의 칼날`.
   - `進撃の巨人 第2期` gives `進撃の巨人`.
   - `Re:Zero 2nd Season` gives `Re:Zero`.
   - `Attack on Titan: The Final Season` gives `Attack on Titan` (the longest match, with the trailing `:` trimmed).
   - `銀魂 第2期` gives `銀魂` (2 CJK characters remain).
   - `86 Season 2` stays unchanged (`86` has 2 characters, below the Latin minimum of 4).
   - `Monogatari Second Season` stays unchanged (word ordinal).
   - These stay unchanged: `Steins;Gate 0`, `Mob Psycho 100`, `86`, `Kaguya-sama: Love is War`.
   - A strip that would leave fewer than 4 normalized characters is not applied.
3. **`has_hangul`** is true for `귀멸`, and false for `ㄱ` (a jamo, not a syllable), `ガ` and `abc`.
4. **`head`:**
   - `Fate/Zero` gives `fate`.
   - `Demon Slayer: Kimetsu no Yaiba` gives `demonslayer`.
   - `Bakemonogatari` gives `None`.
   - `K: Return of Kings` gives `None`, because its head is shorter than 4 characters.
5. `.venv\Scripts\python.exe -m pytest` exits 0 from `data/`.

## Review changes (spec round 1)
The critic ran probes on Python 3.12, where `unicodedata.unidata_version` is 15.0.0.
- **B1.** The 4-character minimum contradicted the `나루토 (애니메이션)` example: `나루토` is 3 characters. CJK titles such as `銀魂`, `化物語` and `나루토` are short. The minimum is now 2 for text containing Hangul, kana or CJK, and 4 otherwise. Design 014 is aligned.
- **H1.** `casefold()` cannot be reproduced in Java: 83 code points differ, among them `ß` and `ς`. The step is now `lower()` / `toLowerCase(Locale.ROOT)` plus two explicit mappings.
- **H2.** Removing every symbol made `Hunter × Hunter` and `Hunter x Hunter` different. `×` now maps to `x`. Letter-like math symbols such as `∀` in *Turn A Gundam* (`∀ Gundam` normalizes to `gundam`) are recorded as a Follow-up for the manual supplement.
- **M1.** The qualifier boundary and the longest-match order are defined, and new examples are added.
- **M2.** The escape wording is clarified. The Windows paths written with doubled backslashes are fixed.
- **Nits:**
  - NFC runs again after removal.
  - The IVS and Mongolian variation selectors are removed.
  - Iteration is by code point, and the Unicode version is stated.
